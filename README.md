# GSB Bugfix Task
## 题面
文件下载接口现在能拿 ../ 和绝对路径读到数据目录外面，前缀判断也能被同名前缀目录绕过。path_guard.py 是核心，tests/test_path_guard.py 15 个红。要修成路径规范化后必须落在 BASE 内，绝对路径、..、空字节、反斜杠、URL 编码穿越都拒绝，同名前缀目录不能绕过。修完 15 个测试后，还要保证 1000 组随机路径没有逃逸，32 线程并发解析不串结果；不许改测试或写死测试路径。边界至少覆盖空路径、..、绝对路径、空字节、同名前缀目录。

## 运行方式
```bash
python -m pytest tests -q
```
